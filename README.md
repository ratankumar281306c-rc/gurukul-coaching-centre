# Gurukul Coaching Centre — V3

A real local full-stack coaching platform starter, not a static HTML demo.

## Included
- Student signup/login
- Student dashboard
- Course catalogue
- Course enrollment
- Lesson/video access after enrollment
- Notes/PDF links
- Tests and MCQ submission
- Automatic score calculation
- Student result history
- Admin dashboard
- Admin CRUD for courses, lessons, tests/questions, notices
- Lead/admission enquiries
- Basic payment-ready API structure
- SQLite database with automatic seed data

## Run
1. Install Node.js 18+.
2. Open this folder in terminal.
3. Run `npm install`
4. Copy `.env.example` to `.env` and edit if needed.
5. Run `npm start`
6. Open http://localhost:3000
